Getting started 🚀

Getting started with papiro is very easy, right now there are 3 ways to set it up.

  • Install papiro locally (recommended only for development or testing)
  • Deploy as a github page
  • Run it as a docker container

Order of the pages

Pages and folders are shown in alphabetical order. To choose the order, start their names with two digits and a dash: 01-get-started.md, 02-installation/, 03-embedding.md. The number only sets the position, it is not part of the address or the name (#/wiki/get-started), so links keep working. Pages without a number go after the numbered ones.
