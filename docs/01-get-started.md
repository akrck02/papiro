- [Deploy as a github page](./installation/github-pages)
- [Run it as a docker container](./installation/docker)

## Order of the pages
---

Pages and folders are shown in alphabetical order. To choose the order, start their names with a number of one or two digits and a dash: `1-get-started.md`, `2-installation/`, or `01-…`, `02-…`. The number only sets the position, it is not part of the address or the name (`#/wiki/get-started`), so links keep working. Pages without a number go after the numbered ones.
